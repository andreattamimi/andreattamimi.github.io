Custom Recovery (TWRP): Backup, Restore, dan Flashing

Posted on May 20, 2026 / 9 min read

Setelah unlock bootloader di Part 1, langkah selanjutnya adalah install custom recovery. Saya ingat waktu pertama kali install TWRP. Rasanya seperti “wow, saya sekarang punya kontrol penuh atas HP saya”. Tapi ternyata ada beberapa hal yang nggak dibahas di tutorial kebanyakan, terutama soal backup strategy dan risiko brick.

Artikel ini membahas custom recovery dari berbagai sudut pandang: apa yang sebenarnya dilakukan, bagaimana cara kerjanya, dan apa yang perlu diperhatikan.

Apa Itu Recovery?

Recovery adalah environment terpisah dari Android. Mini-OS yang bisa jalan tanpa memuat Android utama. Fungsi utamanya:

Stock Recovery vs Custom Recovery

AspekStock RecoveryCustom Recovery (TWRP)
FiturTerbatas (wipe, apply OTA)Lengkap (backup, flash, mount, terminal)
Akses file systemTerbatasFull akses ke semua partition
Install custom ROM❌✅
Backup full system❌✅ (Nandroid backup)
Touch interfaceTergantung deviceFull touch support
Source codeProprietaryOpen source

TWRP vs OrangeFox vs Lainnya

TWRP (Team Win Recovery Project)

TWRP adalah custom recovery paling populer dan paling banyak didukung.

Kelebihan:

  • Device support paling luas
  • Community besar, banyak dokumentasi
  • Interface touch-friendly
  • Build stabil dan teruji

Kekurangan:

  • Interface agak “jadul” (tapi functional)
  • Development kadang lambat untuk device baru

OrangeFox Recovery

Fork dari TWRP dengan UI lebih modern.

Kelebihan:

  • UI lebih clean dan modern
  • Fitur tambahan (scheduler, theme engine)
  • Built-in encryption support yang lebih baik

Kekurangan:

  • Device support lebih terbatas dari TWRP
  • Community lebih kecil

Mana yang Harus Dipilih?

Tip

Kalau device kamu didukung oleh keduanya, coba dulu TWRP. Lebih stabil dan lebih banyak dokumentasi. OrangeFox bisa jadi alternatif kalau kamu ingin UI yang lebih modern.

Install TWRP

Persiapan

  • Bootloader sudah unlock (lihat Part 1)
  • TWRP image untuk device kamu (download dari twrp.me (opens in a new tab) )
  • ADB dan fastboot terinstall di PC
  • Kabel USB berkualitas

Metode 1: Flash via Fastboot (Recommended)

Ini metode paling umum dan paling aman:

terminal
# 1. Download TWRP image untuk device kamu
#    Cari di https://twrp.me/Devices/

# 2. Boot ke fastboot
adb reboot bootloader

# 3. Flash TWRP ke recovery partition
fastboot flash recovery twrp-x.x.x-x-device.img

# 4. Reboot ke recovery
fastboot reboot recovery

Warning

Jangan reboot biasa setelah flash. Beberapa device akan me-return stock recovery jika langsung reboot ke Android. Selalu reboot langsung ke recovery setelah flash.

Metode 2: Install via TWRP App

TWRP punya app resmi yang bisa install recovery langsung dari Android. Tapi metode ini kurang recommended karena:

  • Memerlukan root (counterproductive, kita belum root)
  • Kurang reliable dibanding fastboot
  • App kadang punya iklan

Verifikasi

terminal
# Setelah reboot ke recovery, cek versi TWRP
# Di layar TWRP, tap "About" atau lihat header

# Atau via adb (jika adb sudah enabled di TWRP)
adb shell getprop ro.build.version.incremental

Nandroid Backup: Senjata Utama

Nandroid backup adalah backup lengkap dari seluruh partition, bukan sekadar copy file, tapi bit-for-bit copy dari setiap partition di device. Ini adalah “save point” yang bisa kamu restore kapan saja.

Apa yang Di-Backup?

Cara Backup

  1. Boot ke TWRP
  2. Tap Backup
  3. Pilih partition yang mau di-backup (semua direkomendasikan)
  4. Swipe untuk mulai backup
  5. Tunggu selesai (bisa 10-30 menit tergantung data)

Strategi Backup

Ini yang sering dilupakan orang:

KapanApa yang Di-backupPrioritas
Sebelum unlock bootloaderFull backup via stock recoveryWajib
Sebelum flash custom ROMFull Nandroid backupWajib
Sebelum flash Magisk/KernelSUBoot + System + DataPenting
Setelah setup selesaiFull backupDisarankan
Rutin (mingguan/bulanan)Data sajaOpsional

Tip

Simpan backup di PC atau cloud, bukan hanya di HP. Jika HP brick atau data corrupt, backup di HP juga hilang.

Restore

Warning

Restore akan mengembalikan HP ke persis kondisi saat backup dibuat. Semua data baru setelah backup akan hilang.

Flashing Custom ROM

Setelah install TWRP, kamu bisa flash custom ROM. Ini step-by-step umum:

Persiapan

  1. Download custom ROM (zip file)
  2. Download GApps atau microG (opsional)
  3. Copy ke internal storage HP (atau SD card)

Langkah Flash

terminal
# Via adb sideload (jika file di PC)
adb sideload lineage-xx.x-xxxxxxxx-UNOFFICIAL-device.zip

# Atau langsung dari TWRP:
# 1. Boot ke TWRP
# 2. Tap Install
# 3. Navigate ke zip file
# 4. Swipe untuk flash

Urutan Flash yang Benar

Important

Wipe sebelum flash. Ini membersihkan data lama agar custom ROM bisa install dengan bersih. Yang perlu di-wipe:

  • Dalvik / ART Cache
  • Cache
  • Data (ini akan wipe semua app dan settings)
  • System (untuk clean install)

Jangan wipe Internal Storage kecuali kamu mau kehilangan semua file.

Encryption & File-Based Encryption

Masalah Encryption

Sejak Android 10, banyak device menggunakan File-Based Encryption (FBE). Ini bisa menyebabkan masalah dengan custom recovery:

MasalahPenyebabSolusi
TWRP minta passwordData ter-encryptMasukkan password lock screen
TWRP tidak bisa mount /dataKey mismatchFlash diskrypter atau gunakan OTG
Data corrupt setelah flashEncryption conflictWipe data sebelum flash

Tips Mengatasi Encryption

  1. Sebelum flash custom ROM: wipe data di TWRP (ini akan decrypt)
  2. Setelah flash: Android baru akan encrypt ulang dengan key baru
  3. Jika ingin tetap unencrypted: flash DisableForceEncryption.zip

Tips dari Pengalaman Saya

  1. Selalu backup sebelum flash: saya pernah skip backup “karena cuma ganti kernel” dan akhirnya harus factory reset
  2. Pakai SD card atau OTG untuk backup: internal storage bisa corrupt
  3. Jangan flash ROM yang belum stabil di daily driver: pakai device secondary untuk testing
  4. Baca changelog: beberapa ROM punya known issues yang bisa dicegah
  5. Keep TWRP updated: versi lama bisa punya bug yang menyebabkan brick

Troubleshooting

TWRP tidak bisa mount /data

terminal
# Coba decrypt dengan password lock screen
# Di TWRP, tap Decrypt Data → masukkan password

# Jika gagal, wipe data (ini akan menghapus semua data)
# TWRP → Wipe → Format Data → ketik "yes"

Bootloop setelah flash ROM

  1. Boot ke TWRP
  2. Cek apakah ROM ter-flash dengan benar
  3. Jika tidak, wipe lagi dan flash ulang
  4. Jika masih bootloop, coba flash ROM lain atau restore backup

TWRP hilang setelah reboot ke Android

Beberapa device (terutama Samsung) akan me-return stock recovery setelah reboot. Solusi:

terminal
# Flash TWRP lagi via fastboot
adb reboot bootloader
fastboot flash recovery twrp-x.x.x-x-device.img
fastboot reboot recovery  # langsung ke recovery, jangan ke Android

“Signature verification failed”

Ini terjadi saat signature ROM tidak cocok. Solusi:

  • Di TWRP, matikan signature verification di Settings
  • Atau flash ROM yang sudah terverifikasi

Kesimpulan

Custom recovery adalah tool yang sangat powerful untuk Android. Dengan TWRP, kamu punya kontrol penuh atas backup, restore, dan flashing. Tapi ingat: power = responsibility. Selalu backup, selalu baca dokumentasi, dan jangan flash sembarangan.
